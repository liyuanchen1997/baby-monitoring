# 宝宝监控（Baby Monitoring）

WebRTC 实时监控应用：一部设备（**手机或 PC**）用摄像头拍摄宝宝，另一部设备实时观看，纯局域网运行（两台设备连同一 WiFi），支持 **手机端与 PC 端**。

## 功能

- 📹 实时视频（720p，自动选择后置摄像头；PC 端用笔记本/外接摄像头）
- 🎙 双向语音对讲（按住说话，观看端可哄宝宝）
- 📸 截图 / ⏺ 录制（观看端）
- 🔄 断线自动重连、屏幕常亮、连接状态显示
- 🔔 **动作/哭闹检测**：拍摄端检测到宝宝大幅活动或哭闹时，观看端横幅 + 声音 + 系统通知提醒
- 🎯 灵敏度三档可调（低/中/高）
- 📱 二维码配对：观看端扫码即加入

## 快速开始

### 1. 安装依赖（macOS 开发机）

```bash
brew install mkcert nss   # 生成 HTTPS 证书的工具（仅首次）
npm install
```

### 2. 生成 HTTPS 证书

手机浏览器调用摄像头**必须 HTTPS**，本项目用自签证书，证书需包含电脑的局域网 IP。

```bash
npm run cert
```

### 3. 启动

```bash
npm run dev
```

启动后终端会打印访问地址清单：

```
macOS 本机:      https://localhost:5173
手机访问:        https://192.168.x.x:5173
```

### 4. 手机安装证书（首次，一次性）

另一终端运行 `npm run cert:serve`，手机浏览器访问 `http://<电脑IP>:8080` 下载 rootCA 并安装：

- **iPhone**：下载描述文件 → 设置里安装 → 设置 → 通用 → 关于本机 → 证书信任设置 → 开启完全信任
- **Android**：Chrome 默认不信任用户安装的 CA，**请用 Firefox** 访问（或 Chrome 打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，仅开发用）

证书装好后，手机访问 `https://192.168.x.x:5173` 不再有警告，摄像头权限可用。

## 使用流程

1. **拍摄端**（放宝宝旁的设备，建议手机）：打开页面 → 点「开始监控」→ 允许摄像头/麦克风 → 得到 6 位房间码和二维码。手机保持充电、屏幕常亮、不锁屏
2. **观看端**（家长手里的设备）：扫码，或在首页输入房间码 → 进入实时画面
3. 需要哄宝宝时：按住「说话」按钮即可对拍摄端外放声音
4. 观看端可截图、录制；开启「提醒」后，检测到哭闹/大幅动作会收到横幅 + 声音 + 通知

> 💡 **建议**：拍摄手机放置好后再扫码不便，建议放置前完成配对，或用房间码手动输入。

## PC 端使用

- **作为观看端**：浏览器打开页面输入房间码，桌面横向布局，支持快捷键：`S` 截图、`R` 录制、`F` 全屏、空格键按住说话
- **作为拍摄端**：笔记本摄像头同样可推流（`localhost` 即安全上下文，无需证书警告）
- 本机自测：`https://localhost:5173` 开两个标签页，一个拍摄、一个观看（`?join=<房间码>`）

## 生产部署（可选）

```bash
npm run build
npm run start    # 单端口 3443 提供页面 + 信令
```

## 已知限制

- **拍摄端不能锁屏/切后台**：iOS/Android 网页摄像头在锁屏后会被系统关闭（Web 平台限制，非软件缺陷）。拍摄手机请设置永不锁屏、插电、保持 Safari/Chrome 前台
- iOS Safari 不支持网页系统通知，哭闹提醒仅前台横幅 + 声音
- 哭声检测是启发式算法，可能误报（窗帘飘动、窗外车辆、光影变化）——用「低」灵敏度 + 调整摄像头角度缓解
- 房间码无鉴权，局域网内可被猜测加入（家庭场景可接受）
