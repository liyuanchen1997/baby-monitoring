# 宝宝监控 · 需求文档

> 版本：v1.0（2026-08-15 初始版）｜状态：确认中

## 1. 背景与目标

**背景**：需要一个纯局域网内的实时监控方案：拍摄端设备（手机/PC，置于宝宝旁）用摄像头实时推流，观看端设备（家长）实时查看，无需公网服务器，隐私不出家门。

**目标**：MVP 实现一套基于 WebRTC 的浏览器应用，满足"宝宝在睡觉/玩耍时，家长在另一台设备上实时查看 + 获得异常提醒"的核心诉求。

## 2. 使用场景与角色

| 角色 | 设备 | 职责 |
|---|---|---|
| 拍摄端（Camera） | 手机（推荐）/ PC | 采集摄像头+麦克风，本地检测动作/哭声，向观看端推流，外放家长对讲声音 |
| 观看端（Viewer） | 手机 / PC | 实时查看画面，双向对讲，截图/录制，接收检测提醒 |

**场景**：两台设备连同一 WiFi（同一局域网）；拍摄端放置后长时运行（插电、保持前台、不锁屏）。

## 3. 功能需求

### FR-1 实时视频（P0）
- FR-1.1 拍摄端：后置摄像头优先（`facingMode: environment`），分辨率 720p、24fps
- FR-1.2 观看端：实时画面，全屏查看（移动端横竖屏均可，PC 端窗口/全屏）
- FR-1.3 视频质量：局域网内流畅播放（码率上限 1.5Mbps 可配）

### FR-2 双向语音对讲（P0）
- FR-2.1 观看端按住「说话」按钮，声音经拍摄端扬声器外放（push-to-talk，避免持续回声）
- FR-2.2 拍摄端麦克风始终采集（供对讲 + 哭声检测共用）
- FR-2.3 对讲中抑制哭声误报（AEC + 阈值临时抬高）

### FR-3 截图与录制（P1）
- FR-3.1 观看端一键截图（PNG），支持 `navigator.share` 分享与下载
- FR-3.2 观看端一键录制当前画面 + 声音，生成 mp4/webm 文件下载
- FR-3.3 iOS Safari 走 canvas 录制兜底路径（防黑屏）

### FR-4 动作/哭闹检测提醒（P0）
- FR-4.1 拍摄端动作检测：帧间差分 + 网格统计，判定「轻微活动」
- FR-4.2 拍摄端哭声检测：频带能量 + 声音周期性（voicedness）启发式，判定「哭闹」
- FR-4.3 灵敏度三档（低/中/高），拍摄端可调，即时生效，localStorage 持久化
- FR-4.4 状态机：calm（安静）/ moving（轻微活动）/ crying（哭闹），状态迁移时上报
- FR-4.5 观看端提醒：告警横幅（哭闹红/活动黄）+ 声音提示 + 系统通知（Android/桌面）+ 标题闪烁
- FR-4.6 观看端可关闭提醒；拍摄端显示检测状态与最近事件列表（10 条）

### FR-5 配对与连接（P0）
- FR-5.1 拍摄端创建房间，生成 6 位数字房间码 + 二维码（扫码直达观看端）
- FR-5.2 观看端扫码或输入房间码加入；房间满员/不存在时给出明确错误
- FR-5.3 断线自动重连（WS 指数退避 + ICE 重协商 + 媒体冻结检测三层），观看端离线期间错过的提醒在重连后提示（"错过 N 次"）
- FR-5.4 连接状态显示（未连接/连接中/已连接/重连中/失败），AP 客户端隔离时给出排查提示
- FR-5.5 屏幕常亮（Wake Lock），不支持时提示手动设置

### FR-6 双端适配（P0）
- FR-6.1 移动端：竖屏大按钮、底部操作栏、安全区适配
- FR-6.2 PC 端：≥1024px 居中宽屏布局（视频 + 底部控制栏），快捷键（S 截图 / R 录制 / F 全屏 / 空格对讲）
- FR-6.3 对讲按钮兼容触摸与鼠标事件
- FR-6.4 PC 摄像头（笔记本/外接）可作拍摄端；`localhost` 免证书

## 4. 非功能需求

- **NFR-1 安全**：全链路 HTTPS（局域网自签证书）；媒体走 WebRTC 加密（DTLS/SRTP）；信令不经公网
- **NFR-2 性能**：拍摄端检测 ≤5% CPU 增量（小尺寸 canvas 采样）；长时运行发热可控（720p/24fps）
- **NFR-3 兼容性**：iOS Safari ≥16、Android Chrome 最新、macOS Chrome/Safari；iOS 需 `playsinline`、手势解锁 AudioContext
- **NFR-4 可维护性**：所有可调参数集中于 `src/config.js`；信令协议文档化（见设计文档）；变更记录于 `doc/CHANGELOG.md`
- **NFR-5 UI 设计**：统一"夜灯守护"设计风格（深夜蓝紫 + 夜灯琥珀，见设计文档 §14）；移动/PC 双端响应式；低光环境整夜观看护眼；状态一目了然（呼吸光环）

## 5. 验收标准（真机矩阵）

| 组合 | 视频 | 对讲 | 截图 | 录制 | 重连 | 检测提醒 |
|---|---|---|---|---|---|---|
| iPhone ↔ iPhone | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| iPhone ↔ Android | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| Android ↔ Android | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
| PC ↔ 手机 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

**检测专项**：婴儿哭声录音 → 拍摄端 crying → 观看端横幅+声音；手电筒晃镜头（光照变化）→ 不误报；空调白噪 → 不误报；对讲中说话 → 不误报。

## 6. 边界与已知限制

- 房间码无鉴权（局域网可被猜测加入，MVP 接受）
- 拍摄端锁屏/切后台 → 摄像头被系统关闭（Web 平台限制）；须保持前台+插电+永不锁屏
- iOS Safari 不支持网页系统通知（仅前台横幅+声音）
- 哭声检测为启发式，无法 100% 准确；误报源：窗帘、窗外车辆、光影变化
- 检测事件仅缓存最新状态（离线补发"错过 N 次"，不做完整历史持久化）
